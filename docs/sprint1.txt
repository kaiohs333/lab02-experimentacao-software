(Sprint 1):

  1. collect_repos.py — usa a API GraphQL do GitHub para buscar os top-1000 repos Java por estrelas,
  salvando: nome, estrelas, data de criação, releases, forks. Resultado: data/repositories.csv

  3. Baixar o CK — você precisará baixar o .jar manualmente (vou te passar o link).
